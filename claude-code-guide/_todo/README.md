# _todo — 追加候補と作業メモ

追加コンテンツの候補、レビュー結果、計画、旧版など、資料本体ではない中間物を置く。ここにあるものは**資料の一部ではない**ので、読者向けの体裁は不要。

## 命名

`<種別>-<対象>-<日付 YYYY-MM-DD>.<拡張子>`

| 種別 | 内容 |
|---|---|
| `review` | 章のレビュー結果（公式ドキュメントとの突き合わせ）。`guide-reviewer` サブエージェントの出力先 |
| `plan` | 勉強会や執筆の計画 |
| `archive` | 大きく書き換える前の旧版 |

## いま置いてあるもの

| 名前 | 内容 |
|---|---|
| `archive-19ch-2026-09-09/` | 6 章に再構成する前の全 19 章版。当時の `toc.json`・TODO・19 章専用スクリプトを含む。削った内容（サブエージェント・MCP・プラグイン・自動化・可視化・用語集・ロードマップ）はここにしか残っていない |

## 扱い

- 対応が終わったレビュー項目は、ファイルを消すのではなく「反映済み」と追記して残す
- 役目を終えたファイルは消してよい。2026-09-10 に 19 章版以前のレビュー・計画・旧版と `_source/`（分解前の 1 枚 HTML）を削除した
