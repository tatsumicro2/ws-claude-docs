# _todo — 作業メモ置き場（claude-code-guide）

レビュー結果・計画・差し替え前のアーカイブなど、資料本体ではない中間物を置く。
ここにあるものは**資料の一部ではない**ので、読者向けの体裁は不要。

## 命名

`<種別>-<対象>-<日付 YYYY-MM-DD>.<拡張子>`

| 種別 | 内容 | 例 |
|---|---|---|
| `review` | 章のレビュー結果（公式ドキュメントとの突き合わせ） | `review-ch01-05-2026-09-08.md` |
| `plan` | 勉強会や執筆の計画 | `plan-5weeks-2026-09-08.html` |
| `archive` | 大きく書き換える前の旧版 | `archive-ch01-principles-2026-09-08.html` |
| その他 | プロンプトなど | `agent-core-roadmap-prompt.md` |

## 扱い

- 対応が終わったレビュー項目は、ファイルを消すのではなく「反映済み」と追記して残す（判断の経緯が追えるように）
- 追加コンテンツの候補一覧は [`TODO.md`](../TODO.md) に集約する。ここには置かない
