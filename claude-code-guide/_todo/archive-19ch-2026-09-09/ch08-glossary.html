08

用語集

公式用語集（Glossary）を軸に、本資料で使う語を補って整理しました。補足 は公式用語集にない、本資料独自の項目です。

原理との対応

この章は図 1-1（1-1）の各要素の言葉を一枚で確認する索引です。用語はどれも、図 1-1 の核——LLM・コンテキストウィンドウ・ツール使用・エージェントループ——とそれを取り囲むメモリ・ガードレールのどれかを触る機能に付いた名前にすぎません。そこで各表に「原理」列を設け、3-9 のどの項の実装かを引けるようにしました。廃れないのは原理の側で、変わるのは名前の側です（Headless mode → Non-interactive mode のように、名前は改称されても原理は動きません）。

8-3. この章の持ち帰り

用語集の実用価値は 2 つ——古い記事を読むための変換表と、混同しやすい語の切り分けです。

覚えること仕事での効き目具体的な操作
用語はすべて 3-9 の原理のどれかに還元できる未知の語や他ツールの語に出会っても、「LLM・コンテキストウィンドウ・ツール使用・エージェントループのどれを触るか」で位置づけられる。用語表の「原理」列がその索引3-9 の対応表
Headless mode → Non-interactive modeコミュニティ記事に頻出。同じ -p フラグ、同じ動作検索は現行語で引く
Custom commands → Skills.claude/commands/ は今も動くが、新規は Skills で作るスキルのほうが高機能
Slash commands → Commands製品表記から「Slash」が削除された—
Session / Turn / Checkpoint障害報告や相談で話が噛み合う。Turn は 1 プロンプトへの一連の応答、Checkpoint はプロンプト送信ごとの復元点/rewind は Checkpoint を戻す
Skill / Subagent の一行判別設計会話が速くなる。コンテキストを分けるなら Subagent、分けないなら Skill9-4 の決め手 1 問
意外と知られていない

Checkpoint は git の代わりになりません。追跡されるのはメイン会話がファイル編集ツールで行った変更だけで、Bash 経由の変更・サブエージェントの編集・DB やデプロイなどの外部副作用は戻せません。「/rewind があるから大丈夫」という前提で作業を任せるのが、最も危ない誤解です。
