## 適用手順

1. 上の A を先に、次に B を反映する。C・D は勉強会の回に合わせて順次。
2. 節を足した場合（1-2、および「試してみる」ブロックの追加は節ではないので不要）は `toc.json` の `sections` に追記する。
3. 編集後に必ず次を実行する。

```bash
python3 tools/build_nav.py
python3 tools/check_docs.py
```

4. 相互参照 X-1 のように番号で参照している箇所は、`check_docs.py` では**リンク先の存在**しか検査されない。番号と節タイトルの対応は目視で確認する。次の 1 行で 1〜5 章の章またぎ参照を一覧できる。

```bash
grep -o -h -E '<a href="ch0[6-9][^"]*#s[0-9]+-[0-9]+">[^<]*</a>' claude-code-guide/ch0[1-5]*.html | sort | uniq -c | sort -rn
```
