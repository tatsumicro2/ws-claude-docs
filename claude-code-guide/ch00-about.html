Claude Code 体系的入門/第0章
00

この資料について

何を主軸にし、何を周辺に置き、何を載せないか。読む前に、この資料の立場を先に示します。

0-1. 狙い — 廃れない技術を主軸にする

この資料は、Claude Code をコマンドの集まりとしてではなく、AI エージェントの一実装として説明します。主軸に置くのは、Claude Code に限らず LLM を使うどの道具にも通用する基礎技術です。便利なコマンドや固有の用語は、その基礎技術が製品にどう現れているかを示す例として扱います。

載せるもの・載せないもの

区分何か扱い
コア技術（主軸）LLM の性質、コンテキスト、ツール使用、エージェントループ、記憶と分離、制御図 1-1 で全体を示し、3-9 で原理として説明する。製品が変わっても変わらない部分
周辺技術拡張の仕組み（Skills・Subagents・Hooks・MCP・Plugins）、設定と権限、自動化コア技術の応用として網羅する。「コンテキストとエージェントループのどこを触るのか」を先に、操作を後に
実装の詳細コマンド名、フラグ、バージョン依存の数値、画面の操作必要な分だけ載せる。数値には「v2.1.x 以降」など条件を添え、暗記は求めない

原理から入ると何が変わるか

コマンドだけ覚えた状態原理を理解した状態
失敗したとき、なぜ失敗したのかを説明できない限界を予測できる。「この依頼はコンテキストに入らない」「合否を機械が返せない」と、試す前に分かる
うまくいくプロンプトを、再現性なく引き当てている指示を設計できる。何をコンテキストに置き、何をループの外で強制するかを決められる
別のツールに移ると、知識がゼロに戻る知識を持ち越せる。モデル・コンテキスト・ハーネスの分業は、どのエージェントツールでも同じ
  • 対象：これから導入する開発者、既に使っているが「なぜ効くのか」を説明できない人、チーム／組織への展開を検討する担当者。
  • 前提知識：ターミナル操作と Git の基礎。特定の言語知識は不要です。機械学習の知識も要りません——モデルは「コンテキストを受け取り、次のトークンを返す状態のない推論エンジン」として扱えれば足ります（3-9 LLM）。

0-2. 情報ソースと記述の確度

本資料の記述は、原則として次の優先順位で裏付けを取っています。

優先度ソース位置づけ
1（一次）Claude Code 公式ドキュメント（code.claude.com/docs/ja/…）Anthropic 公式。本資料の記述はほぼすべてここに対応する
1（一次）同 英語版（code.claude.com/docs/en/…）日本語版が古い箇所はこちらに従う。下の注意を参照
1（一次）Claude API ドキュメント（platform.claude.com/docs/…）ツール使用など、Claude Code の下にある API の仕様
2（一次）公式ドキュメント索引 llms.txt全ページの機械可読な一覧。本資料の章立ての網羅性検証に使用
3（一次）Anthropic 公式ブログ / Engineering設計思想・運用パターンの解説
4（準公式）Agent Skills 標準、Model Context ProtocolAnthropic 発のオープン標準。仕様の原典
5（コミュニティ）awesome 系リポジトリ、ClaudeLog ほか非公式。事例収集用。仕様の根拠には使わない

記述の確度の表し方

Claude Code の内部実装は公開されていません。本資料の記述は次の 3 段階のどれかで、既定は「文書化」です。それ以外は本文でその旨を明記します。

確度意味本文での扱い
文書化公式ドキュメントに書かれている挙動既定。出典を Source ブロックに添える
実測手元で観測した数値・挙動「実測」と明記し、日付とモデルを添える（例：7-4）
類推公開されている他のエージェント実装や論文からの推定「類推」と明記。仕様の根拠にはしない。論文には発表年と検証対象モデルを添える
注意

日本語版ドキュメントは英語版より遅れることがあります。本資料の作成時にも、権限モードの既定・非対話実行時の挙動・/memory と /context の役割・自動メモリの保存対象など、複数の箇所で両者が食い違っていました。食い違う場合は英語版が正として扱い、該当箇所には注記を添えています。

Claude Code は更新が速く、機能によっては「v2.1.x 以降」といったバージョン条件が付きます。本資料は 2026年8月時点の公式ドキュメントに基づきます。実運用前に該当ページで最新仕様を確認してください。また、旧 URL docs.claude.com/…/claude-code/… および anthropic.com/engineering/claude-code-best-practices は現在 code.claude.com/docs/… へリダイレクトされます。
