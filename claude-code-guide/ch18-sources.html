情報ソース一覧

本資料の根拠と、継続学習のための情報源。公式／準公式／コミュニティを明確に区別して掲載します。

原理との対応

この章は原理の章ではなく、3-9 の原理を確かめに行く先です。図 1-1（1-1）と 3-9、各章の「原理との対応」が Source に挙げる公式ドキュメント（18-1）と、ツール使用の原典である Claude API ドキュメント（18-2）が「文書化」の根拠で、コミュニティ資料（18-3）は事例集であって根拠にはなりません（0-2）。廃れないのは「一次情報から当たる順序」で、変わるのは URL と掲載機能の一覧です。

18-4. この章の持ち帰り

情報ソースの持ち帰りは 1 つ——公式を Claude 自身に読ませることです。

覚えること仕事での効き目具体的な操作
根拠の等級を分けて読む読んだ記述が「文書化・実測・類推」のどれかを意識すると、そのまま信じてよい範囲と自分で測り直す範囲が決まる。原理（3-9）は公式に文書化された挙動から組み立ててあり、論文との対応づけだけが類推0-2 の 3 段階・3-9 の Source
llms.txt を読ませる全ページの機械可読インデックス。仕様で迷ったら本人に最新を引きに行かせるのが最速で確実「code.claude.com/docs/llms.txt を見て◯◯の仕様を確認して」
日本語版が古いことがある本資料でも複数の相違を確認済み（サブエージェントの上限など）。数値と仕様は英語版で裏を取る/docs/en/ に切り替える
旧 URL はリダイレクトされるdocs.claude.com/ja/docs/claude-code/* のブックマークは新 URL へ更新するcode.claude.com/docs/*
コミュニティ資料は事例集として使うアイデアの収集には有用。仕様の根拠には使わない公式と突き合わせてから採用
配布物は必ず中身を読む他人のスキル・フック・プラグイン・MCP は、あなたの権限で任意のコードを実行しうる信頼できる提供元に限定
意外と知られていない

公式ドキュメントには AI に読ませるための索引が用意されています。llms.txt がそれで、120 ページ超の全ドキュメントが機械可読な形で並んでいます。「この機能の正確な仕様を llms.txt から確認して」と頼めば、二次情報の古さに悩まされずに済みます。この資料を含め、人が書いた解説より公式を引かせるほうが速い場面は多くあります。
